# Agents

Read the repository's `AGENTS.md` first. This example is written against **AIM 6.3** (`proposals/6.3-four-facets.md`, now in the specification): it uses the four facets 6.3 adds — `## Organisation:`, `## Project:`, `## Software:`, `## Service:` — and the `nature` values that go with them. A 6.2 reader rejects those headings as unknown facet types; everything else in the files is 6.2 as specified.

The tree is under `aim/nasa/`. Its root is `nasa`, an organisation; the `README.md` beside this file says what each part shows and where the proposal's claims are exercised. Treat the files as the authority and the README as the guide.
