# Agents

Read the repository's `AGENTS.md` first. This example is written against **AIM 6.3 and 6.4** (`proposals/6.3-four-facets.md`, `proposals/6.4-flow-constructs.md`): the facets Organisation, Project, Software and Service; Flow written as Process and Contract as Operation; a requirement's `from` source; and in the processes a race, `Ends on`, deadlines that end the case, a step over a collection with a child case per item, a timed wait and criteria rules. A 6.2 reader rejects the new headings and words; everything else is 6.2 as specified.

The club's tree is under `aim/tsv/`; `aim/volksbank/` is the bank's provider model beside it, outside the tree. The `README.md` beside this file says what each part shows. Treat the files as the authority and the README as the guide.
